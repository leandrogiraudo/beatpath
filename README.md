# BeatPath

App pessoal de estudo de bateria — **build estático** publicado a partir de um repositório privado.

- Endereço: https://leandrogiraudo.github.io/beatpath/
- Os dados de prática ficam **só no navegador** de quem usa (IndexedDB); nada é enviado a servidor.
- Para levar os dados de um navegador para outro: Configurações → Backup.
